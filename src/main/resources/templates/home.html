主数据工作台

法人、公司、自然人、员工和部门各自有主键。供应商按采购公司加实际供货对象单独建档。公司与分公司都记在 company 上，用 company_type 区分。

法人 0 法律名称与存续 公司 / 分公司 0 登记、账户、股东、版本 自然人 0 姓名与个人联系方式 员工 0 雇佣、任职与汇报 来源材料 0 证照、合同与依据 部门 0 直接归属公司或分公司 供应商 0 准入、合作、联系人与资质 项目 0 成员、预算与交付分工 合同 0 条款、品项与阶段 工时 0 填报、审批与成本率

这一版能做什么

  • 维护五类主数据，并在公司下管理登记版本、银行账户、股东明细和公司版本。
  • 法人可登记非公司证照和法定代表人任期。已经关联公司的法人，证照只在公司登记里维护。
  • 公司类型必须有法人且总公司留空；分公司必须指向一家公司类型的总公司，法人、公司形式和股东留空。
  • 员工详情里维护雇佣、部门任职和汇报线。用人对象在公司与法人中恰好选一个，任职和汇报期间必须落在对应有效期内。
  • 供应商确认时，供货对象在公司、法人、自然人中恰好选一个。同一采购公司对同一对象只留一份档案。联系人、供货类别和资质在详情页维护，状态变化写入版本。
  • 项目客户最多选一个。成员的雇佣和任职必须属于该员工，期间落在对应有效期内。预算未知金额留空，两项都填写时总额才是两者之和。
  • 合同的买方和卖方各自恰好一个。采购合同核对供应商档案。变更保留原条款版本，并复制品项与阶段。未知金额留空，不用零代替。
  • 开票计划和收付款计划分开记录。交付后的验收可以复验尚未通过的数量；累计通过不会把已经通过的部分再计一次，也不能超过已交付数量。
  • 工时只允许期间盖住工作日的项目成员填报。只有工作日当天有效的行政上级可以批准或驳回。批准时按标准成本率计算金额并保留单价快照。驳回必须写原因。
  • 未知号码留空，不写占位空串。信用代码、税号和注册号按主体去重，同一家公司的信用代码与税号可以相同。

费用和发票还不在这一版。
