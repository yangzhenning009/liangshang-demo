# 梁山集团 Demo — 工程工作包拆分

依据：`01-企业领域模型第一版设计.md`、`02-企业领域逻辑Schema第一版.md`  
技术栈：Spring Boot 4 / Spring Data JPA / SQLite / Thymeleaf  
硬规矩：库端无外键、CHECK、业务 UNIQUE；编码走 CloudAgent `new_repo`；未经振宁同意不花钱/订房/发帖/合并。
